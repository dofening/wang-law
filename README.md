# 王定律

**王定律正式发布，为判断一顿饭的进展提出一条基本原则。**

长期以来，饭桌上用「还能吃」判断一顿饭能不能继续。随着菜品陆续上桌，这套办法逐渐显出局限。筷子还能夹，嘴也还能嚼，可再添半碗饭，裤腰就开始紧了。如何判断一顿饭到底吃到了什么程度，成了「再来一点」之前必须回答的问题。

## 定律

> **同一个人在同一顿饭里，通常吃得越多，就会越撑。**

王定律把观察重点从「还能不能吃」转向「已经吃了多少」。前者决定筷子会不会再抬起来，后者决定松腰带时要松几格。

## 饭桌推演

以一顿火锅为例。开饭时，第一盘肉刚下锅，大家已经在商量第二盘点什么。吃到半场，锅里还有几颗丸子，已经有人往椅背上靠。临近散席，服务员端来一盘赠送的炒饭，刚才说「还能吃」的人接过勺子，只给自己盛了两口。

## 应用展望

下一次聚餐，当有人问「要不要再加一个菜」，王定律提供了一项现场参考。先看看桌上还有多少菜，再看看有几个人已经把椅子往后挪。
